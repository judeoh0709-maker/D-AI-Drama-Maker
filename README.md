# D · AI Drama Maker — VS Code 소스 프로젝트

광고·유료 업그레이드·결제 유도가 없는 로컬 개발용 스타터입니다.

## 실행

1. VS Code에서 이 폴더를 **File → Open Folder**로 엽니다.
2. Python 3.10 이상과 [FFmpeg](https://ffmpeg.org/download.html)를 설치합니다. `ffmpeg -version`이 터미널에서 동작해야 합니다.
3. VS Code 터미널에서:

```bash
python -m pip install -r requirements.txt
python server.py
```

4. 브라우저에서 **http://127.0.0.1:8765** 열기
5. 국가·배우·장르·스토리 설정 → **장면 대본 만들기** → **MP4 영상 만들기** → 미리보기 및 다운로드.

생성된 영상은 `exports/` 디렉터리에 저장됩니다. VS Code에서 F5를 누르면 디버그 실행도 가능합니다.

## 기능

- 6개 국가별 가상 배우 캐스팅 (한국·일본·미국·영국·프랑스·이탈리아)
- 브라우저 음성 합성을 활용한 국가별 언어 음성 미리듣기 (OS에 음성이 없으면 대체 음성 사용)
- 남자 주인공 키 **183cm 기본 설정 / 최소 180cm 정책 고정**
- 장면 대본, JSON/TXT 저장, 브라우저 로컬 프로젝트 저장
- **오프라인 스토리보드 MP4 영상 생성** (Pillow + FFmpeg)
- 회원가입·광고·결제 요청 없음. 사용자 데이터는 로컬 PC에서 처리됩니다.

## 현재 구현 범위와 AI 영상 엔진 연결

**중요:** 이 버전의 MP4는 각 장면의 대본을 디자인한 카드로 연결한 *스토리보드 영상*입니다. 배우 얼굴의 실사 생성, 실시간 캐릭터 모션, 립싱크, 감정 연기, 완성된 영화 같은 장면은 **아직 구현하지 않았습니다.** 브라우저 음성 미리듣기는 영상 파일의 오디오 트랙으로 포함되지 않습니다.

향후 실제 AI 동영상 출력을 위해 `server.py`의 `render_video()`를 영상 모델 호출 단계와 합성 단계로 분리할 수 있습니다. 예: 사용자가 직접 운영하는 ComfyUI/오픈소스 이미지·동영상 모델을 로컬 GPU 환경에 연결하고, 주인공 얼굴 참조 이미지를 장면에 전달하고, TTS 및 립싱크 결과를 FFmpeg로 최종 인코딩. 모델과 음성 합성기의 라이선스 및 GPU 최소사양을 확인해야 합니다. 외부 서비스는 별도 과금 가능성이 있으므로 기본 코드에는 연결하지 않았습니다.

## 프로젝트 구조

```
D_AI_Drama_Maker_VSCode/
├── web/index.html        # 사용자 화면 / 국가별 배우 / 대본 / 영상 제작 UI
├── server.py             # 로컬 HTTP API + 스토리보드 PNG → MP4 인코더
├── requirements.txt      # Python 라이브러리
├── exports/              # 생성된 MP4 저장 위치
├── .vscode/launch.json   # VS Code 디버깅 실행
└── README.md
```

## 주의

실제 인물의 얼굴이나 목소리를 당사자 동의 없이 모사하지 않도록 주의하세요. MP4 생성은 CPU와 FFmpeg 설치 상태에 따라 걸리는 시간이 달라집니다. 보안상 서버는 기본값으로 PC 본인만 접근할 수 있는 127.0.0.1에 바인딩됩니다.
